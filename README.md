## Recent research

I co-authored **[A Three-Layer Caching Architecture for Low-Latency LLM Web Search on Commodity CPU Hardware](https://arxiv.org/abs/2609.05463)** with Nihal Gazi.

The paper documents the architecture behind [OreoLook](https://github.com/pollinations/search.elixpo), combining a Redis-backed session context window, semantic query cache, and URL embedding cache. The evaluated deployment reported an **89.3% aggregate Redis keyspace hit rate**, approximately **0.1 ms Redis read latency**, and **1.38 MB measured Redis memory overhead**.

[Read on arXiv](https://arxiv.org/abs/2609.05463) · [Hugging Face paper](https://huggingface.co/papers/2609.05463) · [Live Space](https://huggingface.co/spaces/Elixpo/OreoLook) · [Evaluation dataset](https://huggingface.co/datasets/p-research/oreolook-research-evals)
