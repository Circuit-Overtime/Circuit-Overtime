## Research and open hardware

My research work connects papers to source, artifacts, limitations, citation
metadata, and reproducible evidence.

- **[MonoDiffuse](https://doi.org/10.5281/zenodo.23424654)** — native
  binary-weight training for MNIST diffusion, with repeated-seed artifacts,
  model releases, checksums, and a runnable
  [Diffuino demonstration](https://huggingface.co/spaces/elixpo/diffuino).
- **[OreoLook caching architecture](https://arxiv.org/abs/2609.05463)** — a
  three-layer cache for low-latency LLM web search on commodity CPU hardware,
  accompanied by a public
  [evaluation dataset](https://huggingface.co/datasets/p-research/oreolook-research-evals).
- **[QFabric](https://github.com/elixpo/qfabric)** — contract-driven task
  recovery across Linux and RTOS domains on Arduino UNO Q, with replayable
  decisions, evidence, a technical report, and a released Python package.
- **[OctaBit](https://github.com/elixpo/octabit)** — a documented RISC-style
  eight-bit breadboard computer built with transistor and TTL logic, EEPROM
  microcode, schematics, and a
  [published paper](https://elixpo.com/research/octabit).
- **[WozFormer](https://github.com/elixpo/wozformer)** — an active investigation
  of language-model inference on a 1 MHz 6502 under severe SRAM and EEPROM
  constraints.

The canonical publication records live at
**[research.elixpo.com](https://research.elixpo.com)** and distinguish released
papers, preprints, technical reports, active experiments, and unreviewed work.
